S02 · TOPIC

选题

why this book

为什么在众多世界名著里选《月亮与六便士》？一句话：它把「理想与安稳」这道人人都要面对的选择题，写得最极端，也最适用于影像表达。

i.

经典地位

毛姆 1919 年长篇小说代表作，以画家高更为原型，公认「文学史上最疯狂的一次人生出走」。

ii.

主题共鸣

月亮与六便士 = 理想与现实。冲突强、金句密，天然适合「金句卡 + 旁白」的有声书形态。

iii.

视觉可能

伦敦雾夜、巴黎阁楼、塔希提海岛、焚画名场面——场景跨度大、色彩对比强，为 AI 生成素材提供清晰的视觉谱系。

S03 · VOICE

文案

eighteen lines

旁白共 18 段，写作原则有三：句子短、多设问、关键处直接引用书籍原文。配音使用微软神经网络男声「云健」纪录片音色，语速 -8%，逐段录制并实测时长——每一段旁白的长度，就是对应镜头的长度。

开场 · S1

满地都是六便士，他却抬头，看见了月亮。

巴黎 · S3 · 书籍原文

他说，我必须画画，就像溺水的人，必须挣扎。

收尾 · S7 · 书籍原文

做自己最想做的事，过自己想过的生活，难道就是糟蹋自己吗？

三段摘录覆盖全片三个关键位置：开场钩子、巴黎转折、收尾提问。原句直接引用书籍文本，其余段落全部改写为口语化短句。

逐段配音实测的时长数据反向写回分镜表，形成「文案 → 时长 → 画面」的单向依赖，避免来回改稿。

全文按分镜逐条归档，可在 docs / 旁白脚本_分镜版.txt 查看完整 18 段。

S06 · METHOD

方法

sound first

整条流水线是「先定声音，再定画面」：旁白时长即镜头时长，画面永远贴合声音而不是相反。

01

脚本与分镜

写 18 段旁白，逐段定分镜、媒体与图文卡的出场时机。

02

配音与实测

TTS 逐段渲染并测量时长，误差精确到 0.001 秒。

03

素材生产

AI 生成油画风视频与插画，逐帧质检不合格即重做。

04

代码合成

Remotion 用 React 写视频：Ken Burns 缓推、硬切转场、spring 弹出。

05

渲染输出

30fps 逐帧渲染 5165 帧，H.264 + AAC，另出 720p 字幕版。

06

质检归档

抽帧检查 + 音频电平检测，成片与素材分类归档。

07声音设计

180 秒的程序合成 BGM，A 大调三和弦 pad 之上铺了一串柔和的铃音——刻意避开了"史诗感"，呼应毛姆冷静、不评判的叙述腔调。音量 0.17，5 秒淡入、3 秒淡出，仅在留白处托底，不抢旁白的字句。

合成方式：基频 220Hz 的正弦 + 谐波链 + 慢指数包络，Python 一次性生成 wav，再 ffmpeg 编码入轨。

S08 · SUMMARY

总结

post production

面向「制作系列视频」的长期策略——把这次踩出的形状固化成模板，下次开工时直接复用。

α

声音锁定画面

先逐段生成 TTS 并实测时长，把时长数据反向写回分镜表，让画面永远贴合声音而不是相反。

β

视觉系统化

每幕提取主色，整片统一墨蓝 × 暖金调色 + 胶片颗粒，避免片段与片段之间的视觉割裂。

γ

素材零复用

每个 5 秒素材只出现一次；长镜头内部硬切两段；用 Ken Burns 缓推掩盖有限素材的循环感。

δ

字幕即对齐

下一步用 Whisper 做语音级字幕对齐，告别字符加权近似；字幕版独立导出，保持原版干净。

ε

动效参数化

出场动画的时长、缓动、距离写成可调参数，迁到下一部影片时只换内容不改动画。

ζ

素材分层归档

视频 / 音频 / 字幕 / BGM / 元数据全部按 01-08 类目独立落盘，制作时按目录拼装即可。

S09 · BEHIND

幕后

pitfalls · feedback · path
  • 视频镜头复用第一版 v2 仍能察觉到 5 秒素材的二次出现，长镜头里"同景别再演一遍"。后来用「长镜头内硬切两段」彻底消除循环感。
  • 字幕与语音不贴合字符加权估算代替不了语音识别，停顿、半字、连读全靠猜。下一步必须接 Whisper。
  • 图文卡时机靠经验人物介绍卡、引文卡、金句卡出现时机全靠人脑估算，没有可复用的算法。
  • AI 视频带水印部分生成视频右下角出现极淡水印，肉眼难察，放大后明显。需逐帧 QC。
  • 抠图月亮残留字幕matting 后月亮本体上残留画面里的文字，用 erase 擦除后背景又被填白，最后改用 alpha 圆掩膜 + 羽化收尾。
  • 海外素材下载i.pinimg.com 直连 0 字节，走了本地代理并加 curl -k 才握手成功，过程踩了两次。
  • 字幕版台词与画面错位字幕版初版仍有书页卡整镜字幕上屏，改为"文本卡同类内容"视同跳过，整镜沉默。
  • 多模态脚本并行崩包两个 matting 同时跑导致 urllib3 包损坏，第二次重跑还得手动 force-reinstall。多模态处理不要并行。
  • 书页卡保留第一版人物介绍卡 / 内嵌图文 / 引文卡 / 金句卡都要保留——它们是讲解视频而不仅仅是短图文。
  • 字幕版本要单独出视频做完后单独渲染一份 720p 字幕版用于网页内嵌。
  • 网页先内容后设计不要把「内容 + 设计稿」一次性推，先把八节内容逐字稿过一遍，确认后再做视觉。
  • 眉题不写「数字编辑」「数字编辑 · 第一次作业」改成「第一次作业 · Assignment 1」或更直接的「FILM · 2026」。
  • 信息条学号要明确统一改成 2025106016，全站统一显示。
  • 印章不要「望月」朱砂印章删除，不必要的国风元素。
  • 章节号不要繁体壹贰叁…捌风格不统一，改用 01–08 阿拉伯数字。
  • 风格先试美术馆画册先试"白盒子"画册风，再提供多方向备选，但首次出稿就奔着高级感去。
  • 封面要有冲击力不要模糊的小图，「视图打开就要被吸住」——大排版、深色调、电影感。
  • 视频放到第一屏先看视频，再展开制作内容，不要把视频埋在第七节。
  • 分镜节要展示素材把每一幕的核心画面以轮动形式铺出来，让人看到这部视频是怎么"长"出来的。
  • 总结要写坑与策略踩过的坑、把关人给的意见、后期制作对应策略三类都要列出来，不能只写收获。
  • 作品集网站优先于课程作业页面围绕「这部视频怎么做的」，去掉课程标签与学号条；导航改为 "影片 / 选题 / 旁白 / 分镜 / 视觉 / 方法 / 工具 / 策略 / 幕后"。
  • 第一屏即视频视频用全屏深色播放器 + 大 PLAY 按钮入场，看完向下展开。
  • 入场加仪式感封面入场用月亮绽放动效，1.1s 后淡出，建立"电影开场"基调。
  • 抠图立绘可复用绅士背影用作选题节主形象，金色满月用作视觉节与结尾呼应；抠图资产沉淀为下次复用素材。
  • 轮动比静态更有戏分镜节用横向 snap-scroll + Ken Burns 缓推，让"看分镜"变成"边滚动边观展"。
  • 顶部进度条 + 节序高亮滚动到哪一节一目了然，金色 hairline 串联整页。
  • 数字计数器视觉节 31 / 18 / 7 / 1 等关键数字滚动到视区时做 0 → 目标值的 ease-out 动画。
  • 幕后做三栏 Tab踩坑 / 意见 / 策略三个维度并列，用 Tab 切换，不堆在同一栏让人读不下去。
  • 深底 + 暖金 + 米色字与视频调性一致，避免纯白奶油底（之前版本）"太柔"。
  • 下个项目直接套模板把本套版式 / 交互 / 文件结构沉淀为模板，下次只换内容。
