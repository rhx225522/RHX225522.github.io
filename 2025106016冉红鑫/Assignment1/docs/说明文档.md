## 二、本地测试（nginx）

1. 安装 nginx 后，打开 `nginx.conf`，把 `server` 块的 `root` 指向 `Assignment1` 目录，例如：
   `root  C:/path/to/202506001张三/Assignment1;`
2. `nginx -t` 检查配置 → `nginx`（或 `nginx -s reload`）启动。
3. 浏览器访问 `http://localhost/`（或配置的端口），确认页面、视频、音频均可加载。

> 无 nginx 时也可用 Python 快速验证：在 Assignment1 目录执行
> `python -m http.server 8080`，访问 http://localhost:8080。
