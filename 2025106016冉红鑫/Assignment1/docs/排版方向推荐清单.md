## 方向一 · 美术馆画册「白盒子」★ 当前采用

- **气质参考**：美术馆作品集画册 / 画廊展册
- **配色**：纯白 #FFFFFF + 墨黑 #1C1C1A + 全站唯一金 #B8891D（只给月亮与序号点缀）
- **字体**：宋体系大标题（细字重超大编号），正文宋体 15–16px，英文 Georgia 斜体
- **版式特征**：大留白、超大细字编号 01–08、大图配极小图注、细线分隔、无投影无底色卡片
- **优势**：油画质感截图直接变"展品"，高级耐看，与视频调性最贴
- **风险**：偏素，观感依赖图片质量
- **本页落点**：全站骨架 + 首屏封面大图 + 各节编号版式

## 方向二 · 文学期刊「双栏纸刊」

- **气质参考**：《单读》《读库》纸刊内页
- **配色**：米白 + 黑
- **版式特征**：报眉 + 期号、居中大标题、双栏正文 + 栏间细线、段首首字下沉、页脚居中页码
- **优势**：读书节目气质浓，文字仪式感强
- **风险**：网页双栏阅读动线弱，图片排版受限
- **本页落点**：仅取"首字下沉"用于「03 文案」节导语

## 方向三 · 瑞士国际主义「大字报」

- **气质参考**：国际主义排版海报（Helvetica 学派）
- **配色**：白 + 黑 + 单一金块（或红块）
- **版式特征**：正交网格切分版面、特大黑体标题、大数字当图形用、唯一强调色块
- **优势**：投影远看冲击力最强，答辩场合占便宜
- **风险**：中文黑体排不好易呆板；与油画气质有距离
- **备选**：如需要"汇报感"更强的版本可切换此案

## 方向四 · 画廊展签「长卷」

- **气质参考**：展览现场动线，一节 = 一面展墙
- **配色**：白 + 灰 + 展签
- **版式特征**：图左签右（细竖线分隔）、展签 = 标题 + 出处小字、编号极小（02 / 08）、留白极大、纵向行进如观展
- **优势**："边滚动边观展"叙事独特，最贴合"美术馆画册"主题
- **风险**：页面很长，信息密度低
- **本页落点**：「04 素材」节采用图左签右展签版式

## 方向五 · 报纸「文学副刊」

- **气质参考**：老派报纸文艺副刊
- **配色**：米黄纸色 + 黑 + 一点朱
- **版式特征**：粗细双线报头、三栏密排 + 栏线、方框图位、日期行
- **优势**：呼应 1919 年原著的年代感
- **风险**：密排显旧，与视频油画暖金调性有割裂

## 方向六 · 极简大图「滚动叙事」

- **气质参考**：Apple 产品发布会页
- **配色**：白 + 黑 + 金
- **版式特征**：每屏一焦点、全宽大图、居中短句、滚动触发动画、侧缘进度点
- **优势**：演示最炫、滚动最流畅
- **风险**：信息承载低，八节内容被拆得过长
